# Project 1 - Data Cleaning & Preparation

## Objective

Clean and prepare a raw dataset by handling missing values, checking duplicate records, correcting formatting issues, and improving data consistency.

## Tasks Performed

* Identified and handled missing values
* Checked for duplicate records
* Standardized text formatting
* Corrected date formatting
* Formatted numeric values
* Created a change log for documentation(The Change log sheet file is in the 'Cleaned_Data.xlsx')

## Tools Used

* Microsoft Excel

## Dataset

* 1200 records
* 14 columns

## Output

Cleaned and validated dataset ready for analysis.
